## 1. 开发环境准备

### 1.1 需要安装的软件

#### 必需软件

**Visual Studio 2022**（推荐）

- 下载地址：https://visualstudio.microsoft.com/zh-hans/vs/
- 版本选择：Community（社区版，免费）
- 安装时必须勾选的工作负载：
  - ✅ `.NET 桌面开发` （必选，包含WPF开发工具）
  - ✅ `.NET 8.0 运行时`

**或者使用 Visual Studio Code + .NET SDK**（轻量级选择）

- VS Code下载：https://code.visualstudio.com/
- .NET 8 SDK下载：https://dotnet.microsoft.com/download/dotnet/8.0
- 需要安装插件：C# Dev Kit

#### 推荐软件（可选）

- **Git**：用于版本控制和克隆项目
  - 下载：https://git-scm.com/downloads

### 1.2 检查安装是否成功

打开命令提示符（cmd）或PowerShell，输入以下命令：

```bash
dotnet --version
```

如果看到类似 `8.0.xxx` 的版本号，说明 .NET 8 安装成功！

```bash
# 应该看到类似输出：
# 8.0.100
```

## 3. 打开并运行项目

### 3.1 使用 Visual Studio 2022

#### 步骤1：打开项目

1. 启动 Visual Studio 2022
2. 点击 `打开项目或解决方案`
3. 导航到项目文件夹，选择 `DataVisualizationPlatform.sln` 文件
4. 点击 `打开`

#### 步骤2：还原 NuGet 包

Visual Studio 会自动检测缺失的 NuGet 包并提示还原。

- 如果看到提示"某些 NuGet 包缺失"，点击 `还原`
- 或者右键点击解决方案 → 选择 `还原 NuGet 包`

等待包还原完成（可能需要几分钟，取决于网络速度）。

#### 步骤3：构建项目

- 点击菜单栏 `生成` → `生成解决方案`
- 或者按快捷键 `Ctrl + Shift + B`

查看输出窗口，如果看到 `生成成功`，说明项目构建完成！

```
========== 生成: 成功 2 个，失败 0 个，最新 0 个，跳过 0 个 ==========
```

#### 步骤4：运行项目

- 点击顶部工具栏的 `▶️ DataVisualizationPlatform` 绿色运行按钮
- 或者按快捷键 `F5`（调试运行）
- 或者按快捷键 `Ctrl + F5`（非调试运行）

**第一次运行**：项目会先编译，然后启动应用程序。

#### 步骤5：看到登录界面

如果一切正常，你应该看到一个漂亮的登录界面！

```
┌─────────────────────────────────┐
│                                 │
│          欢迎登录系统           │
│                                 │
│   用户名：________________       │
│                                 │
│   密码：  ________________       │
│                                 │
│        [ 登  录 ]               │
│                                 │
└─────────────────────────────────┘
```

**测试登录**：
- 用户名：输入任意用户名（如 `admin`）
- 密码：输入任意密码（如 `123456`）
- 点击 `登录` 按钮

如果看到主窗口界面，恭喜你，项目运行成功！🎉

### 3.2 使用 Visual Studio Code（替代方式）

## 4. 项目结构初步认识

打开解决方案资源管理器（Solution Explorer），你会看到以下结构：

```
DataVisualizationPlatform (解决方案)
├── DataVisualizationPlatform (主项目)
│   ├── 依赖项
│   │   ├── 程序集              # 引用的DLL
│   │   ├── 包                  # NuGet包
│   │   └── 项目                # 引用的其他项目
│   │
│   ├── ViewModels/             # 视图模型（业务逻辑）
│   │   ├── ViewModelBase.cs    # ViewModel基类
│   │   ├── LoginViewModel.cs   # 登录页面的ViewModel
│   │   ├── MainWindowViewModel.cs  # 主窗口ViewModel
│   │   └── ...更多ViewModel
│   │
│   ├── Views/                  # 视图（界面XAML）
│   │   ├── Login.xaml          # 登录界面
│   │   ├── HomePageA.xaml      # 主页A（折线图）
│   │   ├── HomePageB.xaml      # 主页B（柱状图/饼图）
│   │   └── ...更多View
│   │
│   ├── Models/                 # 数据模型
│   │   ├── EquipmentInfoModel.cs  # 设备信息模型
│   │   ├── FaultReportModel.cs    # 故障报告模型
│   │   └── ...更多Model
│   │
│   ├── Services/               # 服务层
│   │   ├── Navigation/
│   │   │   ├── INavigationService.cs      # 导航服务接口
│   │   │   └── NavigationService.cs       # 导航服务实现
│   │   ├── ExceptionHandling/
│   │   │   └── GlobalExceptionHandler.cs  # 全局异常处理
│   │   └── JsonDataService.cs  # JSON数据服务
│   │
│   ├── Messages/               # 消息类（用于页面间通信）
│   ├── Commands/               # 命令类
│   ├── Converters/             # 值转换器
│   ├── Behaviors/              # 行为类
│   ├── Controls/               # 自定义控件
│   ├── Resources/              # 资源文件
│   │   ├── Styles/             # 样式文件
│   │   └── Images/             # 图片资源
│   │
│   ├── App.xaml                # 应用程序入口（XAML）
│   ├── App.xaml.cs             # 应用程序入口（代码）
│   ├── MainWindow.xaml         # 主窗口（XAML）
│   └── MainWindow.xaml.cs      # 主窗口（代码）
│
└── NavigationBar (子项目)      # 自定义导航栏控件
```

### 4.1 关键文件说明

| 文件 | 作用 | 什么时候会执行 |
|------|------|----------------|
| `App.xaml.cs` | 应用程序启动入口，配置依赖注入 | 应用程序启动时第一个执行 |
| `Login.xaml` | 登录界面的UI定义（XAML） | 应用启动后显示 |
| `LoginViewModel.cs` | 登录界面的业务逻辑 | 登录界面显示时创建 |
| `MainWindow.xaml` | 主窗口的UI定义 | 登录成功后显示 |
| `MainWindowViewModel.cs` | 主窗口的业务逻辑 | 主窗口显示时创建 |

### 4.2 项目的启动流程（简化版）

```
1. 运行程序
   ↓
2. App.xaml.cs 的 OnStartup 方法执行
   ↓
3. 配置依赖注入（注册所有 ViewModel 和 View）
   ↓
4. 显示 Login.xaml 登录窗口
   ↓
5. 用户输入用户名密码，点击"登录"
   ↓
6. LoginViewModel.cs 的 LoginCommand 执行
   ↓
7. 验证通过后，关闭登录窗口
   ↓
8. 打开 MainWindow.xaml 主窗口
   ↓
9. 用户可以点击导航栏切换不同页面
```

**重要概念**：
- **XAML文件**：定义界面长什么样（UI）
- **ViewModel文件**：定义界面的数据和行为（业务逻辑）
- **依赖注入**：自动创建和管理对象，不需要手动 `new`

## 5. 运行项目后做什么？

### 5.1 探索界面功能

试着点击以下功能，观察界面变化：

1. **登录界面**
   - 输入任意用户名和密码
   - 点击"登录"按钮
   - 观察是否进入主界面

2. **主界面导航**
   - 点击顶部的导航栏（MagicBar）
   - 切换到不同页面：主页A、主页B、主页C等
   - 观察每个页面显示的内容

3. **数据可视化页面**
   - 主页A：查看折线图
   - 主页B：查看柱状图和饼图
   - 主页C：查看地图

4. **数据管理功能**
   - 数据分析页面：选择不同年份和月份
   - 设备信息页面：查看设备列表
   - 预约列表：点击卡片看翻转动画

5. **编辑功能**
   - Edit页面：尝试添加、修改、删除设备

### 5.2 查看代码

在 Visual Studio 中，双击任意 `.xaml` 或 `.cs` 文件查看代码：

**推荐先看这些文件**：
1. `Login.xaml` - 看看登录界面是如何用XAML定义的
2. `LoginViewModel.cs` - 看看登录逻辑是如何实现的
3. `App.xaml.cs` - 看看应用是如何启动的

**现在不用完全理解代码**！只需要：
- 大致浏览一下代码结构
- 看看XAML和C#代码的区别
- 感受一下MVVM模式（View + ViewModel）

### 5.3 尝试修改代码（小练习）

#### 练习1：修改登录界面的标题

1. 打开 `Login.xaml`
2. 找到包含 "欢迎登录" 或类似文字的 `TextBlock`
3. 修改文字内容为 "欢迎使用数据可视化平台"
4. 保存文件
5. 重新运行项目（`F5`）
6. 观察登录界面标题是否改变

#### 练习2：修改登录按钮的文字

1. 继续在 `Login.xaml` 中找到登录按钮
2. 修改 `Content="登录"` 为 `Content="立即登录"`

**注意**：修改 `.xaml` 文件后，有时需要重新生成项目才能看到效果。

## 6. 常见问题解决

### 问题1：无法还原 NuGet 包

**错误提示**：
```
无法还原 CommunityToolkit.Mvvm...
```

**解决方法**：
1. 检查网络连接
2. 在 Visual Studio 中，点击 `工具` → `NuGet包管理器` → `包管理器设置`
3. 点击 `清除所有 NuGet 缓存`
4. 重新还原包

或者使用命令行：
```bash
dotnet nuget locals all --clear
dotnet restore
```

### 问题2：找不到 .NET 8.0 SDK

**错误提示**：
```
当前 .NET SDK 不支持将 'net8.0-windows' 作为目标...
```

**解决方法**：
1. 下载并安装 .NET 8.0 SDK：https://dotnet.microsoft.com/download/dotnet/8.0
2. 安装后重启 Visual Studio
3. 重新打开项目

### 问题3：运行时报错 "无法加载程序集"

**可能原因**：项目引用的DLL文件路径不对

**解决方法**：
1. 右键点击解决方案 → `清理解决方案`
2. 再次点击 `生成解决方案`
3. 重新运行

### 问题4：界面显示不正常或者样式丢失

**可能原因**：资源文件未正确加载

**解决方法**：
1. 检查 `Resources/Styles/` 目录下的文件是否存在
2. 重新生成项目
3. 清理并重新生成：
   - `生成` → `清理解决方案`
   - `生成` → `重新生成解决方案`

### 问题5：启动后立即崩溃

**查看错误信息**：
1. 在 Visual Studio 中按 `F5` 调试运行（不要按 `Ctrl+F5`）
2. 查看输出窗口的错误信息
3. 检查是否有未处理的异常

**常见原因**：
- NuGet包未正确还原
- 配置文件错误
- 缺少必要的文件

### 问题6：无法打开 .sln 文件

**错误提示**：
```
此版本的 Visual Studio 不支持该项目类型...
```

**解决方法**：
- 确保安装了 `.NET 桌面开发` 工作负载
- 重新运行 Visual Studio Installer，勾选所需工作负载
