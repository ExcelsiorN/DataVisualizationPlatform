## 页面功能概述

### 功能描述

Data 页面是一个**年度数据可视化页面**，主要功能：

1. **显示年度数据柱状图**：展示 12 个月的预约单数和故障次数
2. **动画效果**：页面加载时柱状图有缓动动画
3. **交互功能**：点击月份区域跳转到该月的详细预约列表
4. **导航参数接收**：可以接收年份参数，显示指定年份的数据

### 1. 字段和属性声明

#### 字段定义


**逐个解释**：

**`DispatcherTimer _animationTimer`**
- **作用**：WPF 定时器，用于驱动动画
- **特点**：在 UI 线程执行，可以安全更新 UI
- **为什么用 readonly**：一旦创建就不会改变引用

```csharp
// DispatcherTimer 基本用法
DispatcherTimer timer = new DispatcherTimer
{
    Interval = TimeSpan.FromMilliseconds(16)  // 约 60 FPS
};
timer.Tick += (s, e) =>
{
    // 每 16 毫秒执行一次（更新动画）
};
timer.Start();
```

**`Json _jsonData`**
- **作用**：数据服务，提供 JSON 数据
- **来源**：`Services/Json.cs`（包含所有静态数据）
- **用法**：通过方法获取不同类型的 JSON 字符串

**`DateTime _animationStartTime`**
- **作用**：记录动画开始时间
- **用途**：计算动画已执行的时间，从而计算进度

**`double _animationProgress`**
- **作用**：动画进度（0.0 到 1.0）
- **绑定**：柱状图控件根据此值显示动画

**`string _currentYear`**
- **作用**：当前显示的年份
- **用途**：点击月份时需要知道是哪一年的哪个月

### 3. 构造函数详解

```csharp
    _currentYear = DateTime.Now.Year.ToString();

    // 2. 创建打开月度数据的命令
    OpenMonthlyDataCommand = new RelayCommand<object>((param) =>

            // 尝试解析月份参数
            if (int.TryParse(param?.ToString(), out int month))
            {
                // 发送导航消息
                WeakReferenceMessenger.Default.Send(new ChangePageMessage
                {
                    PageKey = "ReservationList",
                    Parameter = (month, targetYear)  // 元组参数
                });
            }
            else
            {
                System.Windows.MessageBox.Show("月份参数无效，必须是 1-12 的数字！");
            }
        }
    });

    // 3. 初始化动画定时器
    _animationTimer = new DispatcherTimer { Interval = TimeSpan.FromMilliseconds(16) };
    _animationTimer.Tick += AnimationTimer_Tick;
    StartAnimation();
}
```

### 5. 动画实现

#### StartAnimation（启动动画）

```csharp
private void StartAnimation()
{
    AnimationProgress = 0;                   // 重置进度
    _animationStartTime = DateTime.Now;      // 记录开始时间
    _animationTimer.Start();                 // 启动定时器
}
```

#### AnimationTimer_Tick（定时器回调）

```csharp
private void AnimationTimer_Tick(object sender, EventArgs e)
{
    // 1. 计算已经过的时间
    var elapsed = DateTime.Now - _animationStartTime;

    // 2. 计算进度（0.0 到 1.0）
    var progress = Math.Min(elapsed.TotalMilliseconds / AnimationDuration, 1.0);

    // 3. 应用缓动函数
    AnimationProgress = EaseInOut(progress);

    // 4. 如果动画完成，停止定时器
    if (progress >= 1.0)
        _animationTimer.Stop();
}
```

**进度计算示例**：

```csharp
// 假设 AnimationDuration = 3000ms（3秒）
// 动画开始后 1 秒：
elapsed.TotalMilliseconds = 1000
progress = 1000 / 3000 = 0.333

// 动画开始后 2 秒：
progress = 2000 / 3000 = 0.667

// 动画开始后 3 秒：
progress = 3000 / 3000 = 1.0（完成）
```

#### EaseInOut（缓动函数）

```csharp
private static double EaseInOut(double t)
{
    return t < 0.5
        ? 2 * t * t                  // 前半段：加速
        : -1 + (4 - 2 * t) * t;      // 后半段：减速
}
```

**缓动效果对比**：

```csharp
// 线性动画（无缓动）
t → t
0.0 → 0.0
0.25 → 0.25
0.5 → 0.5
0.75 → 0.75
1.0 → 1.0

// EaseInOut 缓动
t → EaseInOut(t)
0.0 → 0.0
0.25 → 0.125  (慢速启动)
0.5 → 0.5     (中间最快)
0.75 → 0.875  (慢速结束)
1.0 → 1.0

// 视觉效果：开始慢 → 中间快 → 结束慢
```

**缓动曲线可视化**：

```
进度
 1.0 ┤         ╭─────
     │       ╭─╯
 0.5 ┤     ╭─╯
     │   ╭─╯
 0.0 ┼───╯
     └──────────────→ 时间
     0.0  0.5  1.0
```

### 6. INavigationAware 接口实现

```csharp
public void OnNavigatedTo(object? parameter)
{
    // 接收导航参数（年份）
    if (parameter != null)
    {
        string targetYear = parameter.ToString();

    // 页面离开时的清理工作

}
```

**导航参数传递流程**：

```csharp
// 1. 其他页面发送导航消息
```

- 如果不停止，定时器会继续运行
- 持有 ViewModel 的引用，导致内存泄漏
- 浪费 CPU 资源

### 7. INotifyPropertyChanged 实现

```csharp
public event PropertyChangedEventHandler PropertyChanged;

protected virtual void OnPropertyChanged([CallerMemberName] string propertyName = null)
{
    PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(propertyName));
}

protected bool SetProperty<T>(ref T field, T value, [CallerMemberName] string propertyName = null)
{
    if (Equals(field, value)) return false;  // 值没变，不触发
    field = value;                           // 更新字段
    OnPropertyChanged(propertyName);         // 通知 UI
    return true;
}
```

**[CallerMemberName] 特性**：

```csharp
// 自动填充调用方法的名称
public double AnimationProgress
{
    get => _animationProgress;
    set => SetProperty(ref _animationProgress, value);
           // ↑ propertyName 自动填充为 "AnimationProgress"
}

// 等同于：
set
{
    SetProperty(ref _animationProgress, value, "AnimationProgress");
}
```

**SetProperty 的智能优化**：

```csharp
// 如果新值和旧值相同，不触发通知
AnimationProgress = 0.5;  // 触发通知
AnimationProgress = 0.5;  // 不触发通知（值没变）

// 避免不必要的 UI 刷新，提升性能
```

## 常见问题和优化

### Q1：动画不流畅怎么办？

**问题**：动画卡顿，不连续

**原因**：
- 定时器间隔太长（如 100ms）
- UI 线程被阻塞

**解决方案**：

```csharp
// ✅ 使用 16ms 间隔（60 FPS）
_animationTimer.Interval = TimeSpan.FromMilliseconds(16);

// ✅ 避免在 Tick 事件中执行耗时操作
private void AnimationTimer_Tick(object sender, EventArgs e)
{
    // ❌ 不要在这里读取文件、网络请求
    // ✅ 只更新动画进度
    var progress = CalculateProgress();
    AnimationProgress = EaseInOut(progress);
}
```

### Q2：页面切换后动画还在运行？

**问题**：内存泄漏，CPU 占用高

**原因**：定时器未停止

**解决方案**：

```csharp
public void OnNavigatedFrom()
{
    _animationTimer?.Stop();  // ✅ 必须停止定时器
}
```

### Q3：如何改变动画速度？

```csharp
// 修改动画持续时间
public int AnimationDuration { get; } = 2000;  // 2 秒（更快）
public int AnimationDuration { get; } = 5000;  // 5 秒（更慢）
```

### Q4：如何更换缓动函数？

```csharp
// 线性（无缓动）
private static double Linear(double t) => t;

// EaseIn（加速）
private static double EaseIn(double t) => t * t;

// EaseOut（减速）
private static double EaseOut(double t) => t * (2 - t);

// 弹性效果
private static double Elastic(double t)
{
    return Math.Pow(2, -10 * t) * Math.Sin((t - 0.075) * (2 * Math.PI) / 0.3) + 1;
}
```

### 面试要点

**问题 1**：这个页面的动画是如何实现的？

**答案**：使用 DispatcherTimer 每 16ms 更新一次AnimationProgress 属性（从 0 到 1），柱状图控件根据这个进度值绘制柱子的高度，并应用了 EaseInOut 缓动函数使动画更平滑。

**问题 2**：点击月份是如何跳转到其他页面的？

**答案**：通过 WeakReferenceMessenger 发送 ChangePageMessage 消息，MainWindowViewModel 接收消息后调用 NavigationService 进行页面跳转，同时传递月份和年份参数。

**问题 3**：为什么要实现 INavigationAware 接口？

**答案**：INavigationAware 提供了页面导航的生命周期方法，OnNavigatedTo 可以接收导航参数并初始化数据，OnNavigatedFrom 可以清理资源（如停止定时器），避免内存泄漏。
