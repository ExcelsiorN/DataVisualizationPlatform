## 1. 类型系统深入理解

### 1.1 值类型 vs 引用类型

这是 C# 中最重要的概念之一，也是面试高频考点。

#### 什么是值类型？

**值类型**直接存储数据，分配在栈（Stack）上。

```csharp
// 值类型示例
int age = 25;           // int 是值类型
double price = 99.99;   // double 是值类型
bool isActive = true;   // bool 是值类型

// 自定义值类型（struct）
struct Point
{
    public int X;
    public int Y;
}

Point p1 = new Point { X = 10, Y = 20 };
```

**值类型的特点**：
- 存储在栈上（速度快）
- 变量直接包含值
- 赋值时复制整个值
- 默认值为 0 或 false

#### 什么是引用类型？

**引用类型**存储对数据的引用（地址），数据本身在堆（Heap）上。

```csharp
// 引用类型示例
string name = "张三";    // string 是引用类型
object obj = new object(); // object 是引用类型
int[] numbers = { 1, 2, 3 }; // 数组是引用类型

// 自定义引用类型（class）
class Person
{
    public string Name { get; set; }
    public int Age { get; set; }
}

Person person = new Person { Name = "李四", Age = 30 };
```

**引用类型的特点**：
- 引用在栈上，实际数据在堆上
- 变量存储的是对象的地址
- 赋值时复制引用（指向同一对象）
- 默认值为 null

#### 赋值行为差异（重要！）

```csharp
// ========== 值类型赋值 ==========
int a = 10;
int b = a;    // 复制值，b 得到 10 的副本
b = 20;       // 修改 b 不影响 a

Console.WriteLine(a); // 输出：10
Console.WriteLine(b); // 输出：20

// ========== 引用类型赋值 ==========
Person p1 = new Person { Name = "张三", Age = 25 };
Person p2 = p1;    // 复制引用，p2 指向同一个对象
p2.Age = 30;       // 修改 p2 会影响 p1（因为是同一个对象）

Console.WriteLine(p1.Age); // 输出：30（受影响！）
Console.WriteLine(p2.Age); // 输出：30
```

**内存示意图**：

```
值类型赋值：
栈（Stack）
┌─────┬────┐
│ a   │ 10 │
├─────┼────┤
│ b   │ 20 │  ← b 是 a 的独立副本
└─────┴────┘

引用类型赋值：
栈（Stack）         堆（Heap）
┌─────┬────────┐   ┌──────────────┐
│ p1  │ 0x1000 ├──→│ Name: "张三"  │
├─────┼────────┤   │ Age: 30      │
│ p2  │ 0x1000 ├──→│              │
└─────┴────────┘   └──────────────┘
      ↑                 ↑
      └─────────────────┘
    p1 和 p2 指向同一个对象
```

#### 常见值类型和引用类型

**值类型**：
- 整数：`byte`, `short`, `int`, `long`
- 浮点数：`float`, `double`, `decimal`
- 布尔：`bool`
- 字符：`char`
- 结构体：`struct`
- 枚举：`enum`

**引用类型**：
- `string`（特殊，虽然是引用类型但行为像值类型）
- `object`
- 数组：`int[]`, `string[]`
- 类：`class`
- 接口：`interface`
- 委托：`delegate`

#### struct vs class（面试常考）

```csharp
// struct（值类型）
struct PointStruct
{
    public int X;
    public int Y;
}

// class（引用类型）
class PointClass
{
    public int X { get; set; }
    public int Y { get; set; }
}

// 使用对比
PointStruct s1 = new PointStruct { X = 1, Y = 2 };
PointStruct s2 = s1;  // 复制整个结构体
s2.X = 10;
Console.WriteLine(s1.X); // 输出：1（不受影响）

PointClass c1 = new PointClass { X = 1, Y = 2 };
PointClass c2 = c1;  // 复制引用
c2.X = 10;
Console.WriteLine(c1.X); // 输出：10（受影响！）
```

**何时使用 struct？**
- 对象很小（<= 16 字节）
- 表示单个值（如坐标、颜色）
- 不需要继承
- 不会频繁装箱

**何时使用 class？**
- 对象较大
- 需要继承
- 需要引用语义（共享对象）
- 大多数情况下使用 class

### 1.2 装箱（Boxing）和拆箱（Unboxing）

#### 什么是装箱？

**装箱**：将值类型转换为引用类型（`object` 或接口）。

```csharp
int num = 123;          // 值类型，在栈上
object obj = num;       // 装箱：复制到堆上，obj 指向堆中的副本

// 内存变化
// 装箱前：num 在栈上
// 装箱后：num 仍在栈上，堆上新建了一个包含 123 的 object 对象
```

**装箱过程**（系统自动完成）：
1. 在堆上分配内存
2. 复制值类型的值到堆
3. 返回对堆对象的引用

#### 什么是拆箱？

**拆箱**：将引用类型转换回值类型。

```csharp
object obj = 123;       // 装箱
int num = (int)obj;     // 拆箱：从堆复制回栈

// 必须显式转换（强制类型转换）
// 如果类型不匹配会抛出 InvalidCastException
```

#### 性能代价

```csharp
// ❌ 性能差：频繁装箱
ArrayList list = new ArrayList(); // ArrayList 存储 object
for (int i = 0; i < 10000; i++)
{
    list.Add(i);  // 每次都装箱！内存分配 10000 次
}

// ✅ 性能好：使用泛型，无装箱
List<int> genericList = new List<int>();
for (int i = 0; i < 10000; i++)
{
    genericList.Add(i);  // 无装箱，直接存储值
}
```

**装箱/拆箱的代价**：
- 内存分配（堆分配比栈慢）
- 数据复制
- GC 压力增大

#### 常见的隐式装箱场景

```csharp
// 场景 1：字符串拼接
int age = 25;
string message = "我今年 " + age + " 岁";  // age 被装箱为 object

// 优化方案：使用字符串插值
string message2 = $"我今年 {age} 岁";  // 更高效

// 场景 2：集合操作
ArrayList arrayList = new ArrayList();
arrayList.Add(123);  // 装箱

// 优化方案：使用泛型集合
List<int> list = new List<int>();
list.Add(123);  // 无装箱

// 场景 3：接口调用
int number = 42;
IComparable comparable = number;  // 装箱为 IComparable
```

### 1.3 可空类型（Nullable Types）

#### 为什么需要可空类型？

值类型默认不能为 `null`，但有时我们需要表示"没有值"的状态。

```csharp
// ❌ 错误：值类型不能为 null
int age = null;  // 编译错误！

// ✅ 正确：使用可空类型
int? age = null;  // 可以为 null

// 可空类型的本质：Nullable<T> 结构体
Nullable<int> age2 = null;  // 等同于 int?
```

#### 可空类型的使用

```csharp
int? score = null;  // 学生可能没有分数

// 检查是否有值
if (score.HasValue)
{
    Console.WriteLine($"分数：{score.Value}");
}
else
{
    Console.WriteLine("没有分数");
}

// 获取值或默认值
int finalScore = score.GetValueOrDefault(0);  // 如果为 null 返回 0
Console.WriteLine($"最终分数：{finalScore}");
```

#### 空值合并运算符（??）

```csharp
int? a = null;
int? b = 10;

// ?? 运算符：如果左边为 null，返回右边的值
int result1 = a ?? 0;   // result1 = 0（a 是 null）
int result2 = b ?? 0;   // result2 = 10（b 不是 null）

// 实际应用
int? userId = GetUserIdFromDatabase();  // 可能返回 null
int displayId = userId ?? -1;  // 如果为 null 显示 -1
```

#### 空值合并赋值运算符（??=）C# 8.0+

```csharp
int? count = null;

// ??= 运算符：如果左边为 null，才赋值
count ??= 0;  // count 为 null，赋值为 0
Console.WriteLine(count);  // 输出：0

count ??= 10;  // count 不是 null（已经是 0），不赋值
Console.WriteLine(count);  // 输出：0
```

#### 空值条件运算符（?.）

```csharp
// 场景：访问对象成员时，对象可能为 null
Person? person = GetPerson();  // 可能返回 null

// ❌ 不安全：可能抛出 NullReferenceException
string name = person.Name;

// ✅ 安全：使用 ?. 运算符
string? name = person?.Name;  // 如果 person 为 null，整个表达式返回 null

// 实际应用
int? age = person?.Age;  // 如果 person 为 null，age 为 null
int displayAge = person?.Age ?? 0;  // 组合使用 ?. 和 ??

// 链式调用
string? city = person?.Address?.City;  // 多层安全访问
```

#### 空值条件索引访问（?[]）

```csharp
int[]? numbers = GetNumbers();  // 可能返回 null

// ❌ 不安全
int first = numbers[0];  // 可能抛出 NullReferenceException

// ✅ 安全
int? first = numbers?[0];  // 如果 numbers 为 null，返回 null
```

### 1.4 ref、out、in 参数修饰符

#### ref 参数

**ref**：传递变量的引用（地址），方法内外共享同一变量。

```csharp
void Swap(ref int a, ref int b)
{
    int temp = a;
    a = b;
    b = temp;
}

// 使用
int x = 10, y = 20;
Swap(ref x, ref y);
Console.WriteLine($"x={x}, y={y}");  // 输出：x=20, y=10

// ⚠️ 注意：ref 参数必须先初始化
int z;  // 未初始化
// Swap(ref x, ref z);  // 编译错误！z 必须先赋值
```

#### out 参数

**out**：输出参数，方法必须为其赋值。

```csharp
bool TryParseAge(string input, out int age)
{
    if (int.TryParse(input, out age))
    {
        return true;  // 解析成功
    }
    age = 0;  // 解析失败，必须赋值
    return false;
}

// 使用
string userInput = "25";
if (TryParseAge(userInput, out int age))  // C# 7.0+ 内联声明
{
    Console.WriteLine($"年龄：{age}");
}

// ⚠️ 注意：out 参数不需要初始化
int result;  // 未初始化也可以
TryParseAge("30", out result);  // 方法内部会赋值
```

**ref vs out 对比**

| 特性 | ref | out |
|------|-----|-----|
| 传入前是否需要初始化 | 是 | 否 |
| 方法内是否必须赋值 | 否 | 是 |
| 使用场景 | 修改现有变量 | 返回多个值 |

#### in 参数（C# 7.2+）

**in**：只读引用，避免大对象复制。

```csharp
struct LargeStruct
{
    public int[] Data;  // 假设很大
}

// ❌ 性能差：复制整个结构体
void ProcessStruct(LargeStruct data)
{
    // 只读访问
}

// ✅ 性能好：传递引用，但只读
void ProcessStructOptimized(in LargeStruct data)
{
    // data.Data = new int[10];  // 编译错误！不能修改
    int length = data.Data.Length;  // 可以读取
}
```

### 1.5 字符串（String）

#### 字符串的不可变性

```csharp
string str = "Hello";
str = str + " World";  // 看起来修改了 str

// 实际上：
// 1. "Hello" 创建在堆上
// 2. "Hello World" 又创建一个新字符串
// 3. str 指向新字符串
// 4. 原来的 "Hello" 等待 GC 回收

// ⚠️ 性能问题：频繁拼接
string result = "";
for (int i = 0; i < 1000; i++)
{
    result += i.ToString();  // 创建 1000 个临时字符串！
}
```

#### StringBuilder（高效字符串拼接）

```csharp
// ✅ 推荐：使用 StringBuilder
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++)
{
    sb.Append(i);  // 在内部缓冲区修改，不创建新对象
}
string result = sb.ToString();  // 最后生成一次字符串
```

#### 字符串插值（C# 6.0+）

```csharp
string name = "张三";
int age = 25;

// 老式拼接（不推荐）
string msg1 = "姓名：" + name + "，年龄：" + age;

// string.Format（可用但繁琐）
string msg2 = string.Format("姓名：{0}，年龄：{1}", name, age);

// ✅ 推荐：字符串插值
string msg3 = $"姓名：{name}，年龄：{age}";

// 支持表达式
string msg4 = $"明年 {age + 1} 岁";

// 支持格式化
decimal price = 99.99m;
string msg5 = $"价格：{price:C}";  // 输出：价格：¥99.99
```

#### 常用字符串方法

```csharp
string text = "  Hello World  ";

// 1. 去空格
string trimmed = text.Trim();           // "Hello World"
string trimStart = text.TrimStart();    // "Hello World  "
string trimEnd = text.TrimEnd();        // "  Hello World"

// 2. 大小写转换
string upper = text.ToUpper();          // "  HELLO WORLD  "
string lower = text.ToLower();          // "  hello world  "

// 3. 查找
bool contains = text.Contains("World"); // true
int index = text.IndexOf("World");      // 8
bool startsWith = text.StartsWith("  Hello"); // true
bool endsWith = text.EndsWith("World  "); // true

// 4. 替换
string replaced = text.Replace("World", "C#"); // "  Hello C#  "

// 5. 分割
string csv = "张三,李四,王五";
string[] names = csv.Split(',');  // ["张三", "李四", "王五"]

// 6. 拼接
string joined = string.Join(" | ", names);  // "张三 | 李四 | 王五"

// 7. 子字符串
string sub = "Hello World".Substring(0, 5);  // "Hello"

// 8. 判断空
string empty = "";
string? nullStr = null;

bool isEmpty = string.IsNullOrEmpty(empty);      // true
bool isNullOrEmpty = string.IsNullOrEmpty(nullStr); // true
bool isNullOrWhiteSpace = string.IsNullOrWhiteSpace("   "); // true
```

## 2. 面向对象核心概念

### 2.1 封装（Encapsulation）

#### 属性 vs 字段

```csharp
// ❌ 不推荐：公开字段
public class PersonBad
{
    public string Name;  // 字段：无法控制访问
    public int Age;
}

// ✅ 推荐：使用属性
public class PersonGood
{
    // 完整属性（带逻辑）
    private int _age;
    public int Age
    {
        get { return _age; }
        set
        {
            if (value < 0 || value > 150)
                throw new ArgumentException("年龄无效");
            _age = value;
        }
    }

    // 自动属性（简化写法）
    public string Name { get; set; }

    // 只读属性
    public string FullInfo => $"{Name}, {Age}岁";  // 表达式主体属性
}
```

**属性的优势**：
- 可以添加验证逻辑
- 可以设置为只读/只写
- 可以延迟计算
- 可以触发事件（MVVM 重要！）

#### 访问修饰符

```csharp
public class Example
{
    public int PublicField;        // 任何地方都可访问
    private int PrivateField;      // 只有本类可访问
    protected int ProtectedField;  // 本类和子类可访问
    internal int InternalField;    // 同一程序集可访问
    protected internal int ProtectedInternalField; // protected 或 internal

    // 常见用法
    private string _name;  // 私有字段（约定前缀 _）
    public string Name     // 公开属性
    {
        get => _name;
        set => _name = value;
    }
}
```

### 2.2 继承（Inheritance）

```csharp
// 基类
public class Animal
{
    public string Name { get; set; }

    public virtual void MakeSound()  // virtual 允许子类重写
    {
        Console.WriteLine("动物叫声");
    }

    public void Eat()  // 普通方法不能重写
    {
        Console.WriteLine("吃东西");
    }
}

// 子类
public class Dog : Animal  // 继承 Animal
{
    public override void MakeSound()  // override 重写虚方法
    {
        Console.WriteLine("汪汪汪");
    }

    public void Fetch()
    {
        Console.WriteLine("捡球");
    }
}

// 使用
Dog dog = new Dog { Name = "旺财" };
dog.MakeSound();  // 输出：汪汪汪（调用子类方法）
dog.Eat();        // 输出：吃东西（继承的方法）
dog.Fetch();      // 输出：捡球（子类新增方法）

// 多态
Animal animal = new Dog { Name = "小黑" };
animal.MakeSound();  // 输出：汪汪汪（运行时多态）
```

#### base 关键字

```csharp
public class Employee
{
    public string Name { get; set; }
    public decimal Salary { get; set; }

    public Employee(string name, decimal salary)
    {
        Name = name;
        Salary = salary;
    }

    public virtual decimal CalculateBonus()
    {
        return Salary * 0.1m;
    }
}

public class Manager : Employee
{
    public int TeamSize { get; set; }

    // 调用基类构造函数
    public Manager(string name, decimal salary, int teamSize)
        : base(name, salary)  // 调用基类构造函数
    {
        TeamSize = teamSize;
    }

    // 重写并扩展基类方法
    public override decimal CalculateBonus()
    {
        decimal baseBonus = base.CalculateBonus();  // 调用基类方法
        return baseBonus + (TeamSize * 1000);  // 额外奖金
    }
}
```

#### 抽象类

```csharp
// 抽象类：不能实例化，用作基类
public abstract class Shape
{
    public string Color { get; set; }

    // 抽象方法：子类必须实现
    public abstract double CalculateArea();

    // 普通方法：子类可以直接使用
    public void Display()
    {
        Console.WriteLine($"{Color}的形状，面积：{CalculateArea()}");
    }
}

public class Circle : Shape
{
    public double Radius { get; set; }

    // 必须实现抽象方法
    public override double CalculateArea()
    {
        return Math.PI * Radius * Radius;
    }
}

// 使用
// Shape shape = new Shape();  // ❌ 错误：抽象类不能实例化
Circle circle = new Circle { Color = "红色", Radius = 5 };
circle.Display();  // 输出：红色的形状，面积：78.539...
```

### 2.3 接口（Interface）

```csharp
// 接口：定义契约（只有方法签名，无实现）
public interface IRepository<T>
{
    void Add(T item);
    void Delete(T item);
    T GetById(int id);
    List<T> GetAll();
}

// 实现接口
public class EquipmentRepository : IRepository<Equipment>
{
    private List<Equipment> _data = new();

    public void Add(Equipment item)
    {
        _data.Add(item);
    }

    public void Delete(Equipment item)
    {
        _data.Remove(item);
    }

    public Equipment GetById(int id)
    {
        return _data.FirstOrDefault(e => e.Id == id);
    }

    public List<Equipment> GetAll()
    {
        return new List<Equipment>(_data);
    }
}
```

#### 接口 vs 抽象类

| 特性 | 接口 | 抽象类 |
|------|------|--------|
| 继承数量 | 可实现多个接口 | 只能继承一个类 |
| 成员实现 | 只有签名（C# 8 可有默认实现） | 可以有实现 |
| 字段 | 不能有字段 | 可以有字段 |
| 构造函数 | 不能有构造函数 | 可以有构造函数 |
| 使用场景 | 定义能力（能做什么） | 定义"是什么" |

**示例**：

```csharp
// 接口：表示"能做什么"
public interface IFlyable
{
    void Fly();
}

public interface ISwimmable
{
    void Swim();
}

// 类可以实现多个接口
public class Duck : IFlyable, ISwimmable
{
    public void Fly() => Console.WriteLine("鸭子飞");
    public void Swim() => Console.WriteLine("鸭子游");
}
```

## 3. 泛型编程

### 3.1 为什么需要泛型？

**问题**：如何创建一个可以存储任意类型的列表？

```csharp
// ❌ 方案1：使用 object（装箱问题）
ArrayList list = new ArrayList();
list.Add(1);       // 装箱
list.Add("text");  // 可以，但类型不安全
int value = (int)list[0];  // 需要拆箱和强制转换

// ✅ 方案2：使用泛型
List<int> intList = new List<int>();
```

## 4. 委托和事件

### 4.1 委托（Delegate）

**委托**是类型安全的函数指针，可以引用方法。

```csharp
// 定义委托
public delegate void MyDelegate(string message);

// 方法1
public void PrintToConsole(string message)
{
    Console.WriteLine($"控制台：{message}");
}

// 方法2
public void PrintToFile(string message)
{
    File.AppendAllText("log.txt", message + "\n");
}

// 使用委托
MyDelegate del = PrintToConsole;
del("你好");  // 输出到控制台

del = PrintToFile;
del("你好");  // 输出到文件

// 多播委托（调用多个方法）
MyDelegate multiDel = PrintToConsole;
multiDel += PrintToFile;  // 添加第二个方法
multiDel("测试");  // 同时输出到控制台和文件
```

### 4.2 内置委托：Action 和 Func

```csharp
// Action：无返回值的委托

action1();

Action<string> action2 = (msg) => Console.WriteLine(msg);
action2("有1个参数");

Action<string, int> action3 = (name, age) =>
    Console.WriteLine($"{name}, {age}岁");
action3("张三", 25);

// Func：有返回值的委托
Func<int> func1 = () => 42;
int result1 = func1();  // 返回 42

Func<int, int> func2 = (x) => x * 2;
int result2 = func2(5);  // 返回 10

Func<int, int, int> func3 = (a, b) => a + b;
int result3 = func3(3, 4);  // 返回 7
```

### 4.3 事件（Event）

**事件**是对委托的封装，用于发布-订阅模式。

```csharp
// 定义事件发布者
public class Button
{
    // 1. 定义委托类型（或使用内置 EventHandler）
    public event EventHandler? Clicked;

    // 2. 触发事件的方法
    public void Click()
    {
        Console.WriteLine("按钮被点击");
        Clicked?.Invoke(this, EventArgs.Empty);  // 触发事件
    }
}

// 事件订阅者
public class MessageBox
{
    public void ShowMessage(object? sender, EventArgs e)
    {
        Console.WriteLine("弹出消息框");
    }
}

// 使用
Button button = new Button();
MessageBox msgBox = new MessageBox();

// 订阅事件
button.Clicked += msgBox.ShowMessage;

// 也可以使用 Lambda
button.Clicked += (sender, e) => Console.WriteLine("Lambda 响应");

// 触发
button.Click();
// 输出：
// 按钮被点击
// 弹出消息框
// Lambda 响应

// 取消订阅
button.Clicked -= msgBox.ShowMessage;
```

**事件 vs 委托**：

```csharp
// ❌ 公开委托的问题

{

{

}

good.MyEvent += () => Console.WriteLine("A");  // 只能 +=
good.MyEvent += () => Console.WriteLine("B");  // 不会覆盖
```

## 6. 异步编程基础

### 6.1 为什么需要异步？

同步代码会阻塞线程，导致 UI 卡顿或资源浪费。

```csharp
// ❌ 同步代码（UI 会卡住）
private void Button_Click(object sender, RoutedEventArgs e)
{
    // 模拟耗时操作（如网络请求）
    Thread.Sleep(3000);  // UI 线程被阻塞 3 秒！
    MessageBox.Show("完成");
}

// ✅ 异步代码（UI 不卡）
private async void Button_Click_Async(object sender, RoutedEventArgs e)
{
    await Task.Delay(3000);  // 等待 3 秒，但不阻塞 UI 线程
    MessageBox.Show("完成");
}
```

### 6.2 async 和 await

```csharp
// 异步方法的三要素：
// 1. 方法签名包含 async 关键字
// 2. 返回类型是 Task 或 Task<T>
// 3. 方法名以 Async 结尾（约定）

public async Task<string> DownloadDataAsync(string url)
{
    using (HttpClient client = new HttpClient())
    {
        // await：等待异步操作完成
        string data = await client.GetStringAsync(url);
        return data;
    }
}

// 调用异步方法
public async Task ProcessDataAsync()
{
    string data = await DownloadDataAsync("https://api.example.com");
    Console.WriteLine(data);
}
```

### 6.3 Task 和 Task<T>

```csharp
// Task：表示没有返回值的异步操作
public async Task DoWorkAsync()
{
    await Task.Delay(1000);
    Console.WriteLine("工作完成");
}

// Task<T>：表示有返回值的异步操作
public async Task<int> CalculateAsync(int a, int b)
{
    await Task.Delay(1000);  // 模拟计算
    return a + b;
}

// 调用
int result = await CalculateAsync(3, 4);  // result = 7
```

### 6.4 async void 的使用场景

```csharp
// ⚠️ async void 只用于事件处理程序
private async void Button_Click(object sender, RoutedEventArgs e)
{
    await DoWorkAsync();
}

// ❌ 其他地方不要用 async void（无法捕获异常）
public async void BadMethodAsync()  // 不推荐！
{
    await Task.Delay(1000);
    throw new Exception("错误");  // 异常会崩溃应用！
}

// ✅ 应该返回 Task
public async Task GoodMethodAsync()
{
    await Task.Delay(1000);
    throw new Exception("错误");  // 异常被包装在 Task 中
}
```

### 6.5 并行执行多个异步操作

```csharp
// 场景：同时下载多个文件

// ❌ 串行执行（慢）
public async Task DownloadSequentialAsync()
{
    await DownloadFileAsync("file1.txt");  // 等待 1 秒
    await DownloadFileAsync("file2.txt");  // 等待 1 秒
    await DownloadFileAsync("file3.txt");  // 等待 1 秒
    // 总共 3 秒
}

// ✅ 并行执行（快）
public async Task DownloadParallelAsync()
{
    Task task1 = DownloadFileAsync("file1.txt");
    Task task2 = DownloadFileAsync("file2.txt");
    Task task3 = DownloadFileAsync("file3.txt");

    await Task.WhenAll(task1, task2, task3);  // 等待全部完成
    // 总共约 1 秒（并行执行）
}
```

### 7.2 常用 LINQ 操作

```csharp
List<Person> people = new List<Person>
{
    new Person { Name = "张三", Age = 25, City = "北京" },
    new Person { Name = "李四", Age = 30, City = "上海" },
    new Person { Name = "王五", Age = 25, City = "北京" },
    new Person { Name = "赵六", Age = 35, City = "广州" }
};

// 2. Select - 投影（提取字段）

// names = ["张三", "李四", "王五", "赵六"]

var sortedDesc = people.OrderByDescending(p => p.Age).ToList();

// 4. GroupBy - 分组
var groupedByCity = people.GroupBy(p => p.City);
foreach (var group in groupedByCity)
{
    Console.WriteLine($"{group.Key}: {group.Count()}人");
    // 输出：
    // 北京: 2人
    // 上海: 1人
    // 广州: 1人
}

// 5. First / FirstOrDefault
var first = people.First(p => p.Age > 25);  // 李四（找不到会抛异常）
var firstOrNull = people.FirstOrDefault(p => p.Age > 100);  // null（找不到返回默认值）

// 6. Any / All - 判断
bool hasYoung = people.Any(p => p.Age < 30);  // true
bool allAdult = people.All(p => p.Age >= 18);  // true

// 7. Count / Sum / Average
int count = people.Count(p => p.City == "北京");  // 2
int totalAge = people.Sum(p => p.Age);  // 115
double avgAge = people.Average(p => p.Age);  // 28.75

// 8. Take / Skip - 分页
var page1 = people.Take(2).ToList();  // 前 2 个
var page2 = people.Skip(2).Take(2).ToList();  // 跳过 2 个，取 2 个

// 9. Distinct - 去重
var cities = people.Select(p => p.City).Distinct().ToList();
// cities = ["北京", "上海", "广州"]
```
